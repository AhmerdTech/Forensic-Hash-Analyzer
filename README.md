# 🔬 Forensic File Analyzer

A Python-based digital forensics tool for analyzing evidence files, generating cryptographic hashes, extracting file metadata, and producing forensic PDF reports.

## 🚀 Features

- 🔐 MD5 hash generation
- 🔐 SHA-1 hash generation
- 🔐 SHA-256 hash generation
- 📄 File metadata analysis
- 🗂️ Case ID and Evidence ID management
- 👤 Examiner information
- 📝 Evidence description
- 📊 Interactive web dashboard
- 📤 Evidence file upload
- 📑 Automatic forensic PDF report generation

## 🛠️ Technologies

- Python
- Streamlit
- ReportLab
- hashlib
- os
- GitHub Codespaces
